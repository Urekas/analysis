1. 🌐 GitHub 매치 센터 연동

상단 아이콘을 눌러 깃허브에서 호스팅되는 경기 목록과 데이터를 불러올 수 있습니다.

  • Admin 탭에 GitHub 계정의 Personal Access Token (PAT)과 저장소 정보(ID, Repo)를 입력하면 바로 경기 영상(URL)과 XML 데이터를 저장소에 등록할 수 있습니다.
  • 이후 언제든지 대회 목록에서 클릭 한 번으로 영상과 데이터 타이밍을 일치시켜 불러올 수 있습니다.

2. 💻 로컬 파일(영상/XML) 열기

로컬 컴퓨터에 있는 영상을 바로 웹에서 분석할 수 있습니다.

  • 영상 열기 아이콘을 눌러 PC의 mp4, webm 등의 영상을 가져옵니다.
  • 데이터 열기 아이콘을 눌러 경기 분석 XML 파일을 가져오면, 화면 우측 패널에 시간별 이벤트 목록이 자동 생성됩니다.

3. ✏️ 캔버스 드로잉 & 분석 도구

영상 위에 전술 그래픽을 바로 그릴 수 있습니다.

  • 하단 메뉴바에서 색상, 선 굵기, 투명도를 직관적으로 조절할 수 있습니다.
  • 다중선(Polyline)이나 다각형(Polygon)을 그릴 때는 화면을 클릭하여 점을 찍고, 더블클릭하면 도형이 완성됩니다.
  • 그려놓은 드로잉을 저장하려면 좌측 패널 밑쪽의 장면 저장 버튼을 누르면 우측 '장면' 탭 메뉴에 시간이 기록됩니다.

* 각 단축키 입력칸을 누른 후, 원하시는 새로운 키보드 키를 눌러 손쉽게 매핑을 바꿀 수 있습니다.
